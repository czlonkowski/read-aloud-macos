# Chatterbox reference voices

Put 5–10 second WAV clips here, named `<voice_id>.wav` (e.g. `pl_speaker_01.wav`).

Chatterbox Multilingual will use them as the speaker reference for zero-shot
voice cloning of Polish text. If a reference file is missing, the engine will
fall back to its built-in default speaker.

Recommended format: mono, 24 kHz, 16-bit PCM, clean studio-quality audio.
